# Nimbus Notes 3.1

Forum users asked last month why sync was slow, so we rewrote the storage layer. A 10,000-note library now syncs in 9 seconds; before, it took more than a minute. The rewrite is also what real-time collaboration will run on.

Other changes in this release: export can now produce Markdown with front matter for static site generators, attachments over 25 MB upload in the background and resume if the connection drops, and search looks inside attached PDFs.

Ada Ferreira designed the "offline first" model behind the new sync engine. Thanks also to everyone who sent crash reports during the beta.
