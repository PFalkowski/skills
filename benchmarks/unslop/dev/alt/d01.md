## Quick start

Kiln caches compiled outputs, keyed by a hash of their inputs. A build that has run once never compiles the same code twice, and pointing your laptop at the team's shared bucket speeds up local builds too.

1. Install the binary with `cargo install kiln-cache`.
2. Set `KILN_BUCKET` to your bucket name. Leave it empty to cache in a local directory.
3. Run `kiln doctor`. You want 0 warnings before wiring it into CI.

By default the cache holds 50 GB and evicts the oldest entries first. Since version 0.9.3 it supports remote signing keys, which stops a compromised runner from writing poisoned entries.
