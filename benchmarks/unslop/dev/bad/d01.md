## ⚡ Quick Start Guide

Kiln marks a pivotal moment for CI speed — it stores compiled outputs keyed by a hash of their inputs, so code built once is never compiled twice. Additionally, it can enhance local builds when pointed at a shared bucket.

- **Install:** Run `cargo install kiln-cache` to get the binary.
- **Configure:** Set `KILN_BUCKET` to the bucket name, or leave it empty for a local directory.
- **Verify:** Run `kiln doctor` and look for 0 warnings.

The cache holds 50 GB by default and evicts the oldest entries first. Version 0.9.3 adds remote signing keys. I hope this helps!
