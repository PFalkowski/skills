## Quick start

Kiln is a build cache. It stores compiled outputs keyed by a hash of their inputs, so code that has been built once is not compiled again. Point it at a shared bucket and local builds reuse what CI already built.

To install it, run `cargo install kiln-cache`. Set `KILN_BUCKET` to the bucket name, or leave it empty to use a local directory. Then run `kiln doctor` and check that it reports 0 warnings before you add it to CI.

The cache holds 50 GB by default and evicts the oldest entries first when it fills up. Version 0.9.3 adds remote signing keys, so a compromised runner cannot write poisoned entries.
