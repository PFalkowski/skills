# Nimbus Notes 3.1

This release is about sync speed, which forum users asked about last month. It is built on a full rewrite of the storage layer and is the base for the real-time collaboration work coming next.

- A 10,000-note library now syncs in 9 seconds instead of more than a minute.
- The export menu adds Markdown with front matter, so notes move cleanly into static site generators.
- Attachments over 25 MB upload in the background and resume after a dropped connection.
- Search now matches text inside attached PDFs.

Thanks to Ada Ferreira for the "offline first" design behind the new sync engine, and to everyone who sent crash reports during the beta.
