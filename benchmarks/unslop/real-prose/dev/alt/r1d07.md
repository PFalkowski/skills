### How to pick the agent shape (own discretion)

Classify the remaining work on two axes. Breadth is how many independent slices there are. Depth is whether each slice needs hard reasoning.

- Farm (parallel workers). Use it for many independent, mechanical slices such as rename, boilerplate, test scaffolding, bulk file edits and format passes. Model: house worker tier at low effort, all in parallel.
- Chain (sequential steps). Use it for a single complex goal where each step must reason about the last, such as design, architecture, security or an involved refactor. Model: strongest tier available, sequential.
- Mixed. Use it when some slices are mechanical and some are hard. Run a farm for the mechanical slices in parallel, and a chain for the hard nucleus.

Unless depth clearly demands otherwise, default to Farm.
