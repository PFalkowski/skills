- Places are segments joined by `/`. Reuse the rooms that `list` shows. Saving to a place that already holds a memory replaces it (`"replaced": true`), so `recall` it first unless the user asked to replace it.
- If a palace has no remote and lives in a file-synced folder, let the sync finish before another machine uses it, and write from one machine at a time.

| Command | Standard input | Result |
|---|---|---|
| `status` | none | `{scopes: {global, project, session}, projectRoot, hook}`, where each scope is `null` or `{palace, backend, protected, online, remote, privateRemote, kinds, moments, passphrase}`; also `proposed` when global and project are `null` |
| `save` | `{"place", "title", "summary", "text", "kind"}` | `{saved, replaced, synced, scope}` |
| `recall` | `{"place"}` | `{found: true, place, title, summary, kind, saved, text, scope, alsoIn?}` or `{found: false}`; `alsoIn` lists the other scopes holding it |
| `browse` | `{}` or `{"place"}` | `{memories: [{place, title, summary, kind, saved, scope}]}` covering the place and everything under it, without texts, narrowest scope first |
| `list` | `{}` or `{"place"}` | `{children: [names]}` holding the segments one level below |
| `forget` | `{"place"}` | `{forgot, found, scope}`, for the exact place only |
| `sync` | none | `{synced: true}` |
| `check` | none | `{memories, height, nodes, unreachableRemoved}` |
| `unlock` | none | `{removed: <holder record> \| "unreadable" \| null}` |
